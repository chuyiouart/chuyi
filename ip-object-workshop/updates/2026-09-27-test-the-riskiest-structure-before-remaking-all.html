具体问题

角色的脚踝连接不稳、长外套会卡住腿，或者道具穿不过门洞时，直接重做整个人物和场景，成本会一下变高。完整打印或整套加工不只耗材料，还会占用设备和手工时间；如果真正出错的只是一个关节、一段布料活动范围或一处场景接口，大部分投入都没有帮助判断原因。

小测试也不能随便切下一块就做。样件太小，可能没有保留真实厚度、受力方向和相邻零件；样件塞进太多问题，又会变成另一件昂贵的半成品。今天要解决的是：结构已经出现疑点时，怎样挑出最影响后续的一处，用能复查的小样先判断，再决定是否扩大制作。

核心判断

值得先测的部位，通常同时满足三个条件：一旦失败会让后面停下来，结果能用清楚的动作检查，而且可以从整件中单独取出。比如可动人形跨过门槛时，脚踝能否支撑、衣摆会不会挡住关节、手提工具箱能否顺利穿过门洞，都比先做完整墙面装饰更值得测试。

小样是否省成本，不看它做得多小，而看它能否保留真实尺寸、材料关系、装配方向和受力。用同一套通过条件比较两到三个方案，只改变一个主要条件；样件通过后还要放回角色与场景关系中复查。结果不能回答下一步做不做、改哪里，就不算有效的小测试。

步骤或标准

把整件风险缩成一个小样时，测试对象、真实条件和通过标准必须一起保留下来。

  • 把已发现的问题写成一个能检查的句子，例如“角色抬腿跨过门槛时，外套下摆不能卡住髋关节，脚踝也不能松脱”；同时写明失败会影响哪一步。
  • 从整件中划出测试范围，只保留判断所需的相邻部分。脚踝测试至少带上小腿、脚、鞋和地面接触；衣摆测试至少带上髋部、腿部、关节活动范围和真实布料厚度。
  • 按最终计划的真实尺寸制作小样，并记录版本、材料、装配方向和测试动作。暂时无法确认的材料或公差要标成待测试，不能用随手替代品直接宣布通过。
  • 准备两到三个方案，每次只改变一个主要条件，例如脚踝连接长度、衣摆开衩位置或门洞净宽；其他尺寸、材料和动作保持一致。
  • 用相同动作逐个检查：完成装配，重复抬腿和落脚，轻推角色，观察松脱、干涉、布料拉扯、表面损伤和门洞碰撞，并拍下整体与局部。
  • 把结果分成通过、需要修改和不能继续。通过方案放回完整模型或场景中复查重心与相邻结构；没有新增问题，才安排更大的样件或整件制作。

常见错误

小样只有能代表最终结构，才能减少无效重做；下面这些做法会让测试失真。

  • 为了省材料，把样件缩小到非真实尺寸。后果是壁厚、关节松紧、布料弯折和接触面积一起改变，测试结果不能代表最终作品。
  • 只截取坏掉的位置，不带上相邻受力和装配部分。后果是局部看似牢固，放回角色后仍可能被衣物卡住、被场景顶偏或把受力推到旁边。
  • 一个样件同时改连接、材料、姿态和门洞宽度。后果是结果变好也无法知道哪项变化有效，下一版仍要靠猜。
  • 只试一次能不能装上，不重复角色实际动作。后果是关节在抬腿、落脚或反复操作后的松脱与磨损会被漏掉。
  • 局部样通过后直接做整件，不回到完整模型复查。后果是重心、衣摆与场景间隙等整体问题仍可能让整件失败。

与短期课程的关系

这个主题属于第三阶段，也就是打印、灰模与实物测试。做完后要能拿出一个明确风险、真实尺寸的局部样、两到三个单项变化方案、同条件测试记录和结果分类。局部问题通过复测，并且放回完整模型后没有新增干涉、松脱或站立问题，才进入第四阶段的涂装、包装与产品表达。

3 天路线可以围绕一个最影响后续的结构问题，完成测试范围划分、小样、方案比较和一次复测；4–5 天可继续把通过方案放进较大的灰模或场景组件，检查相邻结构。进入下一阶段前，小样、模型版本和测试照片必须互相对应；仍有关键风险时，就回到结构、尺寸或材料选择继续修改。

事实 / 案例 / 完成度边界

本文依据第三阶段“先做局部样再扩大制作”的方法整理。本页计划用原创布制服装可动人形“门隙巡修员”，表现角色跨过门槛时比较脚踝连接、外套活动范围和工具箱通过间隙。当天四张图都是课程方向示意图，不是真实案例，也不是学员作品、真实课堂、已经完成的可动人形、真实委托或商业项目。真实案例必须另有清楚来源、使用许可、模型版本、材料和实物测试记录。

3–5 天能做到哪一步，取决于已有角色、问题范围、材料、设备、加工时间和返工次数。通常只围绕一个优先风险完成真实尺寸局部样、方案比较和首轮复测；复杂可动机构、成套服装、正式成品、批量生产和外协加工要另行评估。课程不承诺一次小样排除全部结构风险，也不承诺商业级成品、流量、订单、展览或销售结果。
