具体问题

AI 三维初模往往先给出一个“看起来接近”的整体，但直播演示真正要解决的不是生成按钮怎么点，而是怎样判断这份初模能否继续修、需要退回哪一层，以及何时才有资格进入打印。轮廓漂移、比例失真、表面破损、薄壁、悬空、部件穿插和重心不稳，会在屏幕预览中被材质与视角暂时遮住；如果不先分类，后续修模会变成没有终点的局部补丁。

另一项困难是把演示过程变成可复核交付。候选模型、人工修正版、打印版 STL 和切片预检若没有统一版本关系，即使现场得到一张漂亮截图，也无法说明使用的是哪份输入、改过什么、哪些风险仍保留。当天需要建立从受控输入、候选筛选、人工修模到 Gate 2 放行的完整证据链，而不是把一次生成误写成可打印成果。

核心判断

AI 初模只负责提供可比较的体块候选，不能直接代表可打印模型。第一轮判断应把问题分为四层：输入是否一致，角色或作品身份是否保留，几何结构是否可修，制造条件是否可检查。输入或身份严重偏离时，应退回输入或换候选；结构问题范围明确时，才进入人工修模；在五天排程内无法稳定修复时，应启用备选或降级出口。

可打印的判断必须落到 Gate 2 证据，而不是依赖屏幕观感。受控模型应具备真实单位、封闭网格、足够厚度、可信重心、清楚分件与接口，并通过切片预检确认朝向、支撑、空心、排液和部件关系。每次修正都要生成新版本并读回检查；只有模型、STL、切片记录与问题清单互相对应，才可以进入首轮打印。

步骤或标准

现场演示可按以下六项推进；每一项都有可见输入、检查动作和放行条件。

  • 冻结受控输入：记录当天采用的正面、侧面、背面、材质或个人草图版本，写明目标尺寸、姿态、识别特征与暂不处理范围；输入不一致时停止生成，不靠后续修模猜测。
  • 并列筛选候选：在相同输入和尺寸条件下比较二至三个初模，逐项检查主轮廓、比例、姿态、识别特征、部件数量与明显缺陷；保留主候选、备选和淘汰原因，不只保存最漂亮的角度。
  • 确定修模边界：把问题标记为比例轮廓、表面网格、薄壁悬空、穿插破面、重心支撑或拆件接口，并判断是局部可修、需要重生成，还是应切换降级方案；每项修改前先写验收条件。
  • 执行人工修模：只使用项目需要的动作修正比例、封闭破面、加厚薄弱区、消除无效穿插、建立支撑与接口；每完成一类问题就保存新版本，并从正侧背和缩略轮廓复检。
  • 导出并读回 STL：确认真实单位、封闭性、部件命名、接口方向和模型版本，再在切片软件中检查朝向、支撑、空心、排液、层间连续性与预计任务；读回不一致时退回模型，不覆盖原文件。
  • 完成 Gate 2 记录：把受控主模型、STL、切片预检、未解决问题、打印优先级和主 / 备 / 降级决定放在同一记录中；全部关键项有证据后才放行，下一阶段进入首轮打印与 Day 3 实体验证。

常见错误

以下错误会让直播看起来顺利，却无法形成可靠的制造交接。

  • 只看正面渲染像不像，不检查侧面、背面和缩略轮廓；后果是体积、重心与遮挡问题被单一角度掩盖，修模后仍可能失去原作识别度。
  • 在输入明显冲突时继续反复生成；后果是候选之间没有共同基准，时间被消耗在随机差异上，也无法说明哪一版更接近目标。
  • 看到破面、薄壁或悬空就随手局部抹平，却不先分类和设验收条件；后果是一个问题被隐藏，新的比例、表面或接口错误又被引入。
  • 把导出 STL 当作 Gate 2 通过，不做切片读回；后果是单位、封闭性、支撑、排液或部件关系错误直到占用设备时才暴露。
  • 覆盖候选、修正版和打印版，只保留最后一个文件；后果是现场演示无法复盘，失败后也无法定位问题来自输入、模型修改还是切片设置。

与五天课程的关系

当天主题对应 Day 2“AI 三维初模与 Nomad 人工修模”及 Gate 2。Day 1 / Gate 1 已经锁定对象、用途、尺寸、视觉输入、版权状态和主 / 备 / 降级范围；本次演示从这些受控输入开始，完成候选筛选、人工修模、拆件判断、STL 导出和切片预检，再由 Gate 2 决定是否放行。

下一阶段是通过 Gate 2 后启动首轮打印，并在 Day 3 完成清洗、固化、拆支撑、灰模检查与 Gate 3 实体验证。若首轮实体暴露变形、细节丢失、接口、重心或装配问题，应回到受控模型做局部修正、重新切片、局部重打或启用降级方案，而不是跳过证据直接进入涂装。
