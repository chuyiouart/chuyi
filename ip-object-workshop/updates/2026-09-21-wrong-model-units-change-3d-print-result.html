具体问题

三维文件里的数字只有配上正确单位，才代表真实大小。角色高度写成 180，如果建模软件按厘米理解、切片软件却按毫米读取，打印结果就可能突然缩小；反过来读错，也可能大到超出设备空间。外形没有变化，不代表尺寸没有出错。

单位错误还会一起改变壁厚、插接孔、脚底接触和预计用料。屏幕上看着够粗的手指，缩小后可能无法成形；原本合适的接口放大后会过松，支撑、打印时间和材料消耗也会跟着变化。若到整件打印才发现，前面的切片和准备都要重做。

核心判断

判断单位是否正确，不能凭模型在屏幕上看起来多大。要同时核对建模软件的单位设置、模型整体高宽深、导出文件的读取方式，以及切片软件显示的最终毫米数。四处结果必须与项目卡上的目标尺寸一致。

文件通过单位检查后，还要看关键小尺寸是否仍能制作。最薄壁、最细杆、插接孔、脚底接触面和角色与场景的连接，都要按真实毫米数测量。AI 或脚本可以帮助找单位设置、批量读取尺寸和列出异常，但换算结果必须由人核对，打印前仍需切片和真实大小局部样。

步骤或标准

给模型建立一条从建模文件到实物小样都能复查的尺寸记录，任何一次导出或导入都不能只看外观。

  • 在项目卡上写明统一单位和目标高、宽、深，并选一个不会因姿势改变的基准，例如脚底到头顶。把这些数值与原画、摆放空间和设备成型范围放在一起核对。
  • 打开建模软件的场景单位，测量模型整体尺寸。不要只看缩放百分比；应用缩放后再次测量，并保存一份修改前文件。
  • 导出 STL 等打印文件，再新建空文件重新导入。检查软件如何解释单位，并测量整体尺寸、最薄壁、接口直径和脚底接触面，数值应与项目卡一致。
  • 把文件放入切片软件，确认显示的毫米尺寸、设备范围和预计材料量。逐层查看薄片、孔洞、悬空位置和异常实心区，不能靠自动缩放让模型“放得进去”。
  • 若单位读错，回到源文件修正场景单位或导出设置，再重新导出；不要在切片软件里随手放大或缩小后就继续，因为壁厚和接口也要重新检查。
  • 选择风险最高的接口或薄片做真实大小局部样，用卡尺测量并试装。文件尺寸、切片尺寸和实物结果能互相对应后，才安排更大的打印。

常见错误

单位问题常被误当成一次缩放就能解决的小事，下面这些做法会让错误继续留在结构里。

  • 只看模型在视窗里占多大，不查看单位和测量值。后果是不同软件用不同方式读取文件，打印件可能突然变大或变小。
  • 导入切片软件后点击“适合平台”就继续。后果是整体虽然放进设备，壁厚、孔径、接口和脚底接触都被一起改变，零件可能无法成形或装配。
  • 只核对角色总高度，不测关键小尺寸。后果是整体大小正确，手指、衣边、连接柱和插接孔仍可能太薄、太松或太紧。
  • 修正单位后不重新切片。后果是旧支撑、材料估算和打印时间仍按错误尺寸计算，实际打印仍会失败或浪费材料。
  • 完全相信 AI 或脚本给出的换算结果。后果是错误输入、场景缩放或导出设置可能没有被发现，自动检查反而把错误带到下一步。

与短期课程的关系

这个主题属于第三阶段，也就是切片、打印、灰模与色彩测试。做完后要确认源文件、重新导入的文件和切片软件都显示同一真实尺寸，关键壁厚与接口没有因单位修正而失效，局部样的卡尺结果也与记录相符。满足这些条件后，下一阶段才进入涂装、包装与产品表达。

3 天路线可以聚焦一个现有模型，修正单位链并完成一个关键部位的真实大小小样；4–5 天可以在此基础上继续局部打印或首版灰模。进入下一阶段前，文件尺寸、切片结果和实物测量必须互相对得上；任何一处不一致，都要回到源文件、导出设置或结构尺寸继续修改。
