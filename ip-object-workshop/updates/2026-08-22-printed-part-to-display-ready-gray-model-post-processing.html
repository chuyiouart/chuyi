从打印件到可展示灰模：后处理完整过程

具体问题

打印机停止工作时，得到的仍只是待处理打印件，不是可展示灰模。表面可能残留树脂，支撑点附近可能有应力和缺口，分件还可能存在翘曲、错位或接缝。若把这些问题都当成“打磨一下”，结构缺陷会被粉尘和补土暂时遮住，真正装配时才暴露。

后处理还会直接影响对象的轮廓、细节和重心。支撑拆除顺序不当会拉断薄片，过度打磨会消失转折和纹理，厚补土则可能掩盖定位错误。Day 3 需要建立一条可检查的处理顺序，让每一步都能回答：问题是什么、动作是否有效、对象能否进入 Gate 3。

核心判断

后处理的优先级是安全与结构、装配、表面，而不是先把外观磨得均匀。清洗和固化条件必须符合所用材料与设备规范；之后先找断裂、翘曲、薄弱连接、排液异常和重心问题，再处理支撑痕、层纹与小缺口。结构级问题不能靠厚补土代替修正。

可展示灰模的判断也不等于“看起来够白、够平”。同一版本应能稳定干装，轮廓和姿态在多角度保持一致，接缝与修补区在侧光下可读，保留问题有明确记录。满足这些条件，才有依据选择进入色彩测试、局部重打或降级为结构验证样。

步骤或标准

以下动作按先安全、再结构、后表面的顺序执行；每一步都保留版本、问题和处理结果。

  • 完成取件、清洗与固化：按材料和设备规范处理，确认表面无未固化树脂与明显黏腻，再进入手工拆撑；记录打印版本和安全处理状态。
  • 建立缺陷分级：先标记断裂、翘曲、薄弱连接、排液和重心，再标记接缝、支撑痕、层纹与小缺口；结构级问题优先处理。
  • 分区拆除支撑：区分远离细节、贴近细节和承重区域，分组拆除并逐组检查薄边、尖端与轮廓，避免一次性施加集中应力。
  • 有限打磨与修补：从合适粒度逐步处理，曲面使用贴合垫块并在侧光下复核；只对可修复的小缺口和接缝薄层补土。
  • 先干装再固定：用定位销、夹具或临时固定检查部件对齐、姿态、接缝和重心；超出修补范围时回到局部重打或分件调整。
  • 完成灰模复核：在侧光、正面、侧面和转台观察中检查轮廓与表面，记录已修复、待处理和接受保留的问题，再作 Gate 3 选择。

常见错误

以下错误会把可局部处理的问题扩大为不可逆损伤，或让灰模在进入涂装后暴露更明显的缺陷。

  • 打印件一取下就大面积打磨；后果是结构问题尚未分类便被粉尘掩盖，薄边、转折和装配基准还可能被磨损。
  • 一次剪掉所有支撑；后果是应力集中在细长部件与尖端，出现崩裂后也难以判断是哪一组支撑和动作造成。
  • 用厚补土填平所有缝隙；后果是错位、翘曲或定位错误只被暂时遮住，轮廓连续性、装配强度和后续涂层仍会失败。
  • 只在正面和柔光下检查；后果是侧面接缝、层纹、凹坑与重心偏移被遗漏，底漆和涂装会进一步放大它们。
  • 把可展示灰模写成最终成品；后果是对五天完成度、涂装、包装和量产阶段形成不准确预期。

与五天课程的关系

当天主题对应 Day 3“切片、打印、灰模与色彩测试”以及 Gate 3 实体验证。Gate 3 不是只确认打印成功，而是检查清洗固化、结构稳定、分件装配、接缝、轮廓、表面和问题记录，决定这个实体能否继续向前。

完成本阶段后，下一阶段进入配色色板、基础涂装或重点局部涂装，并在 Day 4 继续保护层、包装方向和产品化表达。若结构或装配未通过，则优先局部重打、调整分件或把当前件降级保留为结构验证样，而不是用涂装掩盖问题。
