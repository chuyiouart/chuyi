这些内容如果没有在发布前整理清楚，页面很容易出现旧照片配新模型、缩略图重复、模型太大打不开，或者说明超出实物证据的问题。今天只解决一件事：把同一件作品的图片、展示模型和说明整理成能回查的一组。

核心判断

一组可以进入作品页的资料，至少要回答三个问题：是不是同一件作品和同一版本，各自准备给谁看、解决什么问题，别人能不能从原文件和实物重新找到依据。文件多不代表资料完整，能对应才算有用。

图片负责说明轮廓、颜色、尺度和材料细节；GLB（一种适合网页展示的三维模型文件）负责在线查看；STL等制造文件仍要单独检查，不能因为网页模型能转动就当成可以打印。AI可以帮忙列清单、找重复和提示缺项，最后仍由人打开文件、核对实物并决定采用哪一版。

步骤或标准

先从一个准备上线的作品开始，不要把多个角色和多个版本同时倒进同一个文件夹。

  • 锁定当前实物或主模型，记录它的版本、目标用途和仍未完成的部分；旧版资料先保留，但不要混进当前发布组。
  • 挑选一张完整主图、必要的背面或侧面图、材料细节图和尺度证据图；检查是否来自同一件作品，是否清楚，是否存在重复机位。
  • 逐个打开网页展示模型，确认方向、比例、材质显示和加载是否正常；制造文件另做封闭性、壁厚、连接和切片检查，不混用结论。
  • 把说明中的尺寸、材料、部件、完成阶段和使用边界逐项对照图片、模型、实物及来源记录；找不到依据的内容删除或标成待确认。
  • 统一能长期理解的文件命名和分组，保留原文件、网页用副本、图片导出和来源说明；不要只留下压缩后的发布文件。
  • 在桌面和手机上预看页面需要的主图、画廊、模型和文字顺序；缺项进入待补清单，确认无误后才交给发布步骤。

常见错误

发布资料最常见的问题，往往来自版本、用途和证据被混在一起。

  • 看到文件名里写着‘最终版’就直接采用。后果是旧照片、旧模型和当前实物可能被错误地放在同一页面。
  • 只挑好看的正面图，不留背面、细节和尺度证据。后果是材料、接口和实际大小无法从页面复查。
  • 把GLB能在网页中转动当成STL已经可以打印。后果是壁厚、封闭性、连接和切片问题会被漏掉。
  • 让AI根据图片自动补尺寸、材料或完成度。后果是猜测会进入公开说明，并与实物和来源记录冲突。
  • 为了文件夹看起来整齐而删除原文件。后果是后续无法重新导出、追查来源或修正网页版本。

与短期课程的关系

这项练习属于阶段5的独立站、三维展示与持续发布。做完后要能指出当前作品页使用了哪些图片、哪个展示模型、哪些说明，以及每一项怎样回到原文件和实物。进入发布验收前检查的是这种对应关系，不是文件夹是否看起来整齐。

3天聚焦路线可以围绕一个作品完成资料盘点、主图与细节图选择、一个网页模型检查和有限说明；4–5天可继续制作页面草稿、优化图片、测试手机与桌面显示。真实链接、模型加载、图文一致和版权没有检查完，就不进入公开发布。
