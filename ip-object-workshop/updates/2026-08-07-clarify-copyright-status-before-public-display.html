具体问题

公开展示一件 IP 或角色，不只是在图片下写上作者名字。进入 Day 1 时，原画、合作设定、参考素材、AI 辅助图、字体、纹样与既有三维文件可能来自不同主体；如果没有逐项记录来源、权利人、授权范围与可公开状态，后续模型、过程图、网页和社媒内容就无法判断哪些可以使用。

版权状态含混会同时影响制作与发布。无权改编的形象可能不应进入三维，无权公开的参考图不能出现在过程材料里，只允许内部学习的文件不能被放进网站；若等到 Day 4 或 Day 5 才检查，已经完成的修模、打印、拍摄和页面可能需要撤换，项目版本也会失去可追溯性。

核心判断

版权检查的目标不是给作品贴一个笼统的“原创”标签，而是为每项输入建立可复核记录：内容是什么、来自哪里、由谁拥有或授权、允许进行哪些改编、允许在哪些渠道展示、是否有地域或期限限制，以及需要怎样署名。无法确认的项目应明确标为待核验，而不是默认可用。

Gate 1 的放行依据是制作范围与公开范围同时清楚。一个对象可以具备进入结构转译的视觉条件，却暂时不具备公开展示权限；此时应把内部验证版本与公开版本分开，替换无权使用的输入，或缩小展示范围。只有来源、权限、版本和用途能够对应，后续三维、实体与发布资料才有稳定基线。

步骤或标准

可用以下六项建立版权状态表。每项都应对应具体文件或素材，并留下可复核证据、当前结论和下一动作。

  • 列出全部输入：逐项登记原画、草图、合作设定、参考图、字体、纹样、AI 辅助内容、现有模型和素材文件；为每项写明文件名、版本与当前用途。
  • 确认来源与权利主体：区分个人原创、共同创作、委托、已获授权、公共领域、开放许可和仅作参考；无法确认来源的素材标记为待核验，不并入公开版本。
  • 核对授权范围：检查是否允许改编、三维化、实体制作、课堂操作、网站展示、社媒发布与商业测试，并记录署名方式、期限、地域和再授权限制。
  • 拆分内部与公开版本：内部研究资料与可公开输入使用不同目录和版本号；网站、社媒与招生材料只读取状态明确且允许公开的文件。
  • 处理冲突与缺口：对合作权利未确认、参考素材过近或许可范围不足的部分，执行补充书面确认、替换、重画、删除或降级展示，并记录决定依据。
  • 执行 Gate 1 复核：确认项目卡、版权状态表、公开边界、受控视觉输入、用途、尺寸、结构风险及主 / 备 / 降级方案一致；未通过时不得进入公开内容链。

常见错误

以下做法会把可在输入阶段解决的权利问题带入成本更高的制作和发布阶段。

  • 只写“原创”，不登记共同创作者、委托关系和素材来源；后果是无法确认谁能授权改编与公开，发布时容易出现权属争议。
  • 把“网上能看到”理解为可以下载、改编和商用；后果是参考图、字体或纹样可能超出许可范围，网页和社媒素材必须撤换。
  • 获得展示许可后默认同时获得三维化、复制和销售许可；后果是制作行为超出授权，实体样、包装方向和市场测试无法安全继续。
  • 把内部参考图直接放进过程展示；后果是即使最终对象已替换元素，公开页面仍可能传播无权展示的原始内容。
  • 口头确认后不记录日期、范围和版本；后果是团队无法证明当前文件对应哪次许可，后续修改也无法判断是否仍在授权范围内。

与五天课程的关系

这一主题对应 Day 1“方向判断与结构转译”及 Gate 1。当天需要把已有 IP / 角色资产，或由想法、草图和初步设定形成的视觉输入，连同来源、权利主体、授权范围、公开边界、用途、尺寸、结构风险和主 / 备 / 降级方案一起写入受控项目记录。Gate 1 检查可制作范围与可公开范围是否一致。

Gate 1 通过后，下一阶段进入 Day 2 的 AI 三维初模与 Nomad 人工修模，并由 Gate 2 检查模型、GLB、STL 与可打印性。版权状态仍随版本传递：模型使用了新输入、替换了素材或扩大了公开用途时要重新复核；未通过 Gate 1 的项目先补授权、替换输入或缩小范围。
