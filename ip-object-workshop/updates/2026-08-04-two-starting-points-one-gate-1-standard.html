同一门课，两种入口：已有作品和只有想法

同一门五天课程可以接收两种起点，但两种起点带来的并不是同一种资料。已有 IP / 角色资产的人通常已经有原画、角色设定、系列视觉或三维文件，却可能缺少背面、底部、遮挡处、材质、版权状态与实体用途等制造输入；现成内容越多，越容易误把“已经画完”当成“已经可以进入三维”。 只有想法、草图或初步设定的人面对的是另一类缺口：故事和关键词可能很多，但具体对象、轮廓、姿态、用途与尺寸尚未收敛。如果一开始就要求两类人提交相同格式的成熟原画，前者的结构风险会被掩盖，后者又会被不必要的门槛挡住；Day 1 也无法据此形成稳定的 Gate 1 输入。

具体问题

同一门五天课程可以接收两种起点，但两种起点带来的并不是同一种资料。已有 IP / 角色资产的人通常已经有原画、角色设定、系列视觉或三维文件，却可能缺少背面、底部、遮挡处、材质、版权状态与实体用途等制造输入；现成内容越多，越容易误把“已经画完”当成“已经可以进入三维”。

只有想法、草图或初步设定的人面对的是另一类缺口：故事和关键词可能很多，但具体对象、轮廓、姿态、用途与尺寸尚未收敛。如果一开始就要求两类人提交相同格式的成熟原画，前者的结构风险会被掩盖，后者又会被不必要的门槛挡住；Day 1 也无法据此形成稳定的 Gate 1 输入。

核心判断

两种入口的区别只存在于输入准备阶段，不代表课程目标、验收标准或后续生产链分成两套。已有资产要做的是筛选、核权和补足结构信息；早期想法要做的是把故事、关键词、参考方向与使用场景转成第一版可见输入。两条路径最终都要落到同一张项目卡：一个具体对象、一个主要用途、预计外接尺寸、关键辨识点、版权与公开边界，以及主方案、备选方案和降级方案。

Gate 1 只检查这些输入是否足以支持下一阶段，不按绘画资历、文件数量或画面精细度判断。已有作品如果结构和权限不清，仍应待补；初步设定如果对象、用途、尺寸和必要视图已经明确，也可以进入后续三维生成。共同门槛是可复核，而不是起点看起来更成熟。

步骤或标准

先按起点分别整理，再用同一套 Gate 1 清单合流。每一步都应留下文件或记录，并标记“已具备、待补、需降级”，不能只靠口头描述。

  • 识别起点：已有 IP / 角色资产者列出现有原画、设定、三维文件、版本与版权状态；只有想法、草图或初步设定者写下故事核心、三至五个关键词、参考方向、希望做成的物品和使用场景。
  • 各自补齐输入：已有资产重点补正面、侧面、背面、底部、遮挡处和材质参考，并标记不可改的辨识点；早期想法先收敛为一个对象，形成第一版轮廓、姿态、色彩与材质方向，不扩写完整世界观。
  • 统一填写项目卡：两类起点都写清一个主要用途、预计外接尺寸、最需要验证的问题、五天目标、版权与公开边界，并把不确定项单独列出。
  • 统一做结构预判：按真实尺度检查重心、落地点、薄片、细杆、悬空件、遮挡关系、拆件与装配；无法由现有资料确认的部位不得交给生成工具自行猜测。
  • 统一建立三套范围：主方案保留核心辨识点，备选方案降低姿态或细节风险，降级方案改为半身、浮雕、局部样或更小验证对象；每套方案都写明要验证什么。
  • 执行 Gate 1：只有当用途、尺寸、受控视觉输入、结构风险、版权边界和主 / 备 / 降级方案均可复核时才进入 Day 2；缺项则补资料、澄清权限或缩小范围。

常见错误

下面的错误会把“入口不同”误解成能力分级，或把输入缺口拖到成本更高的阶段。

  • 把已有作品等同于可直接制造，不检查背面、厚度、重心和版权边界；后果是 Day 2 初模可能建立在缺失或无权公开的信息上，后续修模与发布都要返工。
  • 要求只有想法的人先独立完成成熟原画或三维模型；后果是课程入口被错误抬高，参与者把时间花在并非 Gate 1 必需的精修上，仍没有明确实体目标。
  • 把两类起点拆成两条互不相干的课程路线；后果是项目卡、版本和 Gate 标准不统一，后续无法在同一条三维、打印、实体和发布链中验收。
  • 只比较画面完成度，不比较用途、尺寸和待验证问题；后果是看起来更完整的方案反而可能结构风险更高，有限五天排程被错误占用。
  • 让生成工具补写缺失结构或授权事实；后果是不确定信息被固化进模型与公开素材，来源、责任和可制造性都无法追溯。

与五天课程的关系

这一主题直接对应 Day 1“方向判断与结构转译”及 Gate 1。已有 IP / 角色资产者从筛选现有对象、核对版权和补结构视图开始；只有想法、草图或初步设定者从故事、关键词、参考方向和使用场景形成第一版视觉输入。两者随后共同锁定用途、尺寸、结构风险与主 / 备 / 降级方案。

Gate 1 通过后，两种起点进入同一个下一阶段：Day 2 的 AI 三维初模与 Nomad 人工修模，并在 Gate 2 检查受控模型、GLB、STL、真实尺寸、厚度、连接、重心、拆件与可支撑性。Gate 1 未通过时应先补资料或缩小范围，不能用后续工具替代入口判断。

事实 / 案例 / 完成度边界

本文依据公开课程基线中的两类起点、Day 1 与 Gate 1 整理。当天规划的四张图片只用于示意两类输入如何分别准备并汇入同一项目卡和 Gate 1，不是学员案例、真实课堂、真实咨询或已经完成的制作成果。真实案例只有在来源、授权、文件版本、制作记录与完成状态可核验时才能单独标注；示意图不能替代真实案例。

五天内的目标是按项目实际情况形成第一版可继续发展的文件、验证样与表达资料，而不是把所有起点推进到相同精度。完成度受输入成熟度、结构复杂度、尺寸、设备、材料、打印排程与修正次数影响；课程不承诺人人完成商业级精修、一次打印成功、正式包装印刷、批量生产、正式展览、授权成交或销售，也不承诺统一实体件数或统一完成等级。
