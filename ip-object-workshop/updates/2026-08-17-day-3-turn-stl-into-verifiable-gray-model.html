Day 3 到底做什么：把 STL 变成真实灰模

STL 通过切片预检，只能说明数字文件具备进入制造的条件，不能证明实体一定成立。朝向、支撑、空心、排液、层高和尺寸会共同改变打印风险；屏幕上不明显的薄弱连接、悬垂细节和重心问题，可能在取件、清洗、固化或拆支撑时才暴露。如果把“文件可切片”直接等同于“作品已经完成”，问题就会被推迟到最耗设备时间和材料的环节。 Day 3 的任务因此不是追求一件立刻精致的成品，而是取得第一批可触摸、可测量、可记录的实体证据。灰模要回答轮廓是否保留、部件是否能装配、表面和细节是否可读、支撑痕是否可处理、重心是否可信，以及哪些区域应局部重打。没有这些检查，后续涂装只会遮住尚未解决的结构问题。

核心判断

灰模是一轮结构验证，不是“还没上色的半成品”。判断重点应从屏幕观感转向实体状态：尺寸读回是否一致，主体与配件是否完整，薄壁和连接是否承受取件及装配，接触面是否稳定，关键识别特征是否在真实尺度下仍然清楚。只有能被测量、拍照并写入问题清单的结果，才构成 Gate 3 的证据。

第一轮打印也不必默认整件一次完成。对耗时长、结构复杂或风险集中的对象，应优先打印接口、薄壁、悬垂、底座或高识别细节等关键样；根据结果选择继续完整打印、局部修模后重打，或降级为灰模、局部样和数字展示。这样能把有限排程用于验证最关键的不确定性，而不是重复消耗整件任务。

步骤或标准

以下检查按制造顺序执行，并为每一步保留可复核记录。

  • 冻结打印任务：确认 STL 版本、真实单位、目标尺寸、部件清单、打印工艺和主 / 备 / 降级出口；切片前后文件版本不一致时停止任务。
  • 完成切片预检：检查朝向、支撑接触点、空心与排液孔、层高、底部接触、预计耗时和材料需求；保存切片截图或任务记录，不只保留口头判断。
  • 安全取件与后处理：按设备和材料要求完成取件、清洗、固化与拆支撑；记录断裂、变形、残液、支撑痕和表面损伤的位置，不用打磨先掩盖原因。
  • 执行灰模检查：测量整体尺寸与关键接口，从正面、侧面、背面和接触面检查轮廓、重心、装配、细节丢失和表面连续性，并拍摄同一光线下的证据图。
  • 决定修正范围：区分可通过打磨或补土处理的问题、必须回到模型或切片修正的问题，以及需要启用降级出口的问题；优先局部重打，不默认整件重打。
  • 完成 Gate 3 记录：把灰模或局部样、切片记录、问题清单、修正决定和配色色板准备放在同一版本链中；通过后才进入色彩测试与 Day 4 的涂装表达。

常见错误

以下错误会让灰模看起来推进得很快，却无法形成可靠的实体验证。

  • 只要打印机完成任务就认定成功；后果是尺寸偏差、内部残液、接口错位和重心问题未被记录，装配或后续固化时仍会失败。
  • 为了让灰模看起来干净，先大面积打磨、补土或上底漆再检查；后果是支撑、朝向和层纹造成的问题被掩盖，无法判断下一版应改模型还是改切片。
  • 一个局部断裂就立刻重打整件；后果是重复占用设备和材料，却没有先验证薄壁、支撑接触或拆件方案是否需要调整。
  • 只看正面照片，不测尺寸、不看侧背和接触面；后果是轮廓、装配、悬垂和稳定性问题被单一视角隐藏，Gate 3 缺少有效证据。
  • 灰模尚未通过就进入完整涂装；后果是时间投入到不稳定实体上，后续修模或重打会使涂装工作全部作废。

与五天课程的关系

当天主题对应 Day 3“切片、打印、灰模与色彩测试”及 Gate 3 实体验证。Day 2 / Gate 2 已经提供受控主模型、STL、拆件方案和切片前检查；Day 3 将这些数字条件转成灰模或关键局部样，并用尺寸、结构、装配、表面和问题记录决定实体是否可继续。

完成 Gate 3 后，下一阶段先建立配色色板与涂装顺序，再进入 Day 4 的基础涂装、包装方向、产品说明和发布检查。若灰模未通过，应回到模型或切片做局部修正、局部重打或启用降级出口，不能跳过实体证据直接进入涂装与包装。

本文依据课程主基线中的 Day 3 与 Gate 3 要求整理。当天规划的原创“潮壳信使”四图只用于示意一个原创设计玩具怎样从切片任务、三种姿态比较、支撑与断裂检查推进到灰模交接；它们是课程方向示意图，不是学员作品、真实课堂、真实委托或已经完成的打印案例。真实案例必须另有来源、授权、模型版本、切片记录和实体状态证据，示意图不能替代这些事实。
