同一件作品如何导出 GLB 和 STL

同一件三维作品通常需要同时服务两种后续任务：网页中的在线查看，以及切片、打印或制造沟通。GLB 和 STL 都能从三维软件导出，但它们保存的信息并不相同。若只确认“导出成功”，没有先锁定用途、版本、尺寸、坐标和部件关系，同一对象会在两个文件中出现比例不一致、姿态漂移、材质丢失或拆件关系冲突。 这种不一致会破坏 Day 2 的交接。网页端可能拿到带材质但版本过旧的 GLB，打印端可能拿到尺寸未确认或部件未闭合的 STL；后续发现问题时，又无法判断错误来自主模型、导出设置还是文件被混用。双文件输出的重点不是多生成两个后缀，而是证明它们来自同一受控主模型，并分别满足数字展示与实体制造的检查条件。

具体问题

同一件三维作品通常需要同时服务两种后续任务：网页中的在线查看，以及切片、打印或制造沟通。GLB 和 STL 都能从三维软件导出，但它们保存的信息并不相同。若只确认“导出成功”，没有先锁定用途、版本、尺寸、坐标和部件关系，同一对象会在两个文件中出现比例不一致、姿态漂移、材质丢失或拆件关系冲突。

这种不一致会破坏 Day 2 的交接。网页端可能拿到带材质但版本过旧的 GLB，打印端可能拿到尺寸未确认或部件未闭合的 STL；后续发现问题时，又无法判断错误来自主模型、导出设置还是文件被混用。双文件输出的重点不是多生成两个后缀，而是证明它们来自同一受控主模型，并分别满足数字展示与实体制造的检查条件。

核心判断

先建立一个受控主模型，再从同一版本分出两条明确出口。GLB 面向网页与数字展示，应检查对象身份、姿态、层级、坐标、材质或贴图引用、文件体积和目标查看器可读性；STL 面向切片与制造，应检查真实单位、封闭网格、法线、薄壁、拆件、接口、重心和切片可读性。两条出口共享身份和版本证据，但不能用一套检查替代另一套。

导出完成也不等于 Gate 2 通过。只有文件名与版本可追溯、GLB 在目标查看环境中正确显示、STL 在目标切片环境中保持尺寸和部件关系，并且差异与遗留风险被记录，双文件才具备交接条件。若主模型仍有身份或结构问题，应先退回修正，而不是反复改导出参数掩盖源头问题。

步骤或标准

以下六项必须绑定同一主模型版本执行，每项都留下文件、截图、数值或检查记录。

  • 锁定受控主模型：记录项目名、版本号、目标实体尺寸、坐标方向、姿态、主体与配件清单；导出期间不得静默替换模型或缩放基准。
  • 整理数字展示出口：为 GLB 清理对象层级与无关数据，确认材质和贴图来源、朝向、原点、动画状态及文件体积；在目标网页查看器中完成旋转、缩放和材质读取检查。
  • 整理制造出口：为 STL 确认单位、封闭性、法线、最小厚度、部件穿插和拆件边界；每个部件按约定命名，并保留可装配的接口与接触面。
  • 分别导出并命名：文件名包含项目、用途、版本与日期；GLB 和 STL 不共用模糊的“final”名称，旧版移入明确归档而不是覆盖。
  • 执行双端读回：GLB 重新导入或在目标查看器打开，核对身份、姿态、材质与层级；STL 在目标切片器打开，核对尺寸、部件、网格与切片连续性。
  • 建立交接记录：写明两个文件来自哪个主模型、各自通过项、遗留风险和下一责任环节；STL 只有满足 Gate 2 条件后才进入 Day 3 首轮切片与打印。

常见错误

以下错误会让两个看似可打开的文件失去共同版本和后续用途。

  • 分别从两个未标记的模型副本导出 GLB 和 STL；后果是网页展示与打印对象的比例、姿态或细节不同，后续无法用同一问题记录修正。
  • 把 GLB 能显示当作材质完整，只检查缩略图；后果是外部贴图路径、透明材质、坐标或对象层级在目标网页环境中失效。
  • 把 STL 能导入切片器当作可打印；后果是单位错误、薄壁、非封闭网格、穿插和接口问题被带入支撑与打印阶段。
  • 用“final、final2、最新版”命名并覆盖旧文件；后果是主模型、导出设置和实际交付无法追溯，修正也无法准确回写。
  • 为了减小 GLB 体积直接破坏主模型，再从该副本导出 STL；后果是显示优化污染制造出口，结构细节和打印尺度可能一起改变。

与五天课程的关系

当天主题对应 Day 2“AI 三维初模与 Nomad 人工修模”及 Gate 2。Day 1 / Gate 1 已锁定对象、版权状态、视觉输入、目标尺寸和主 / 备 / 降级范围；Day 2 选定并修正受控主模型后，从同一版本导出面向网页展示的 GLB 和面向制造的 STL，并分别完成读回检查。

GLB / STL 与 Gate 2 记录完成后，下一阶段进入 Day 3。STL 用于切片、支撑、打印与灰模验证，并在 Gate 3 根据实体结果决定继续、局部重打或降级；GLB 保留为数字展示资产，并在 Day 5 进入个人独立站与在线三维查看。
