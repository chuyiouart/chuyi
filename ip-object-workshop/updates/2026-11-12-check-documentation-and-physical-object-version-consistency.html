具体问题

说明写的是三片背部页签，网页照片里却只看见两片；展示模型用了新配色，桌上的实物还保留旧接口。每份资料单独看都像是完整的，但放在一起时，可能并不属于同一版本。

今天要解决的是怎样让AI先帮助整理说明、照片、展示模型和实物之间的可见差异，再由人回到原始来源和真实对象确认。重点不是相信文件名或生成一份漂亮报告，而是找出哪一项对不上、应该退回哪里核查。

核心判断

同一版要靠内容对应，不靠文件名相似。可以先选几项能复查的特征，例如轮廓、部件数量、颜色分区、接口形状、尺寸记录和拍摄角度，把每项分别对应到说明、照片、展示模型与实物。

AI适合从多份资料中提取比较项、标出疑似冲突和提醒缺失视角，但它看不到未提供的底面、内部结构或真实材料状态。发现冲突时，最终判断必须回到带来源的原文件、受控模型和实物读回；无法确认的项目继续标为未核对。

步骤或标准

把资料和实物放到同一条核对链里，差异才有明确去处。

  • 锁定本次要核对的对象，收齐说明、原始照片、展示模型、制造文件或记录、实物和各自来源；缺失项明确留空。
  • 先由人工选出少量可复查特征：整体轮廓、部件数量、颜色分区、突出结构、接口、底面和已记录尺寸，不让AI自行补猜。
  • 让AI按资料逐项摘出可见内容，并在输出里区分直接看到、文字说明和无法确认；每条差异保留对应来源。
  • 把照片角度和展示模型转到与实物相近的视角，逐项核对页签、腕部、鞋底和接口；被遮挡的部位补拍或另行读回。
  • 发现不一致时先暂停沿用，回查原文件、修改记录和实物状态，确认是旧资料、错文件、拍摄遮挡还是实物确有变化。
  • 只在来源和实物能够对应后更新说明或展示；尺寸、公差、材料批次、内部结构和制造质量仍按各自方法另行验收。

常见错误

版本混用往往不是没有资料，而是资料之间没有逐项对应。

  • 看到文件名里有相同日期或“最终版”就当成同一版。后果是旧照片、旧模型和新实物可能被错误地放在一起。
  • 只把一张正面图交给AI核对整件作品。后果是背面、底部、接口和被遮挡部件无法确认，缺失信息被误写成一致。
  • 让AI在冲突资料里自动选择最新的一份。后果是没有来源和修改记录支撑的猜测会覆盖真实版本关系。
  • 发现一个颜色不对就重写全部说明。后果是轮廓、部件和接口等本来能确认的内容也失去稳定基准。
  • 可见特征对应后就宣称制造验收通过。后果是尺寸、公差、内部结构、材料批次和耐用情况仍未实测。

与短期课程的关系

这项练习属于阶段4的产品说明与版本一致性检查，也会调用前面阶段留下的模型、实物、照片和材料记录。做完后应能指出每条公开说明对应哪一份来源、哪一个实物特征，以及哪些差异仍待确认。

3天聚焦路线可以围绕一个角色整理一组资料、建立有限核对项并完成一次实物读回；4–5天可继续补拍缺失角度、修正展示模型或说明，并复查网页素材。进入下一阶段前，关键差异要有处理决定，无法核对的项目不能写成已经一致。
