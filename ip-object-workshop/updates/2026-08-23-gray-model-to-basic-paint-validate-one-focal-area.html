灰模到基础涂装，现场完成一个重点局部

灰模结构通过检查后，重点局部仍不能直接靠一次厚涂变成“完成效果”。底漆状态、明度关系、分色边界、涂层厚度和表面光泽都会改变局部识别度；如果先在整件上铺色，错误会扩散到更大的返工面积，还可能覆盖接缝、纹理和装配基准。 重点局部通常同时包含最高识别特征与最难处理的曲面，例如面罩边缘、叶片纹理、透明嵌件接口或软硬材质交界。Day 3 的现场验证要把它缩小为可检查任务：先冻结灰模状态，再比较层序和明度，最后用薄层、遮盖与侧光读回，确认这个局部是否具备进入 Day 4 整体涂装的条件。

核心判断

重点局部的价值不在于提前做出一块“最漂亮”的区域，而在于用最小面积验证整件作品最关键的涂装条件。合格验证必须绑定同一灰模版本、底漆、材料、颜色配方、层序和观察光线；任一条件变化，都不能把旧样直接当成新结论。

判断是否通过，要同时看三件事：三阶明度能否保持轮廓和焦点，分色边界在曲面与接口处是否干净，薄层叠加后细节是否仍清楚。通过后才把配方和顺序扩展到整件；不通过时只调整局部样、遮盖方法或颜色比例，不用厚涂掩盖结构和表面问题。

步骤或标准

以下标准按“冻结条件—比较方案—局部执行—读回记录”的顺序完成，每一步都留下可复查结果。

  • 冻结受检状态：记录灰模版本、底漆颜色、表面修补区、待涂局部尺寸和观看距离；发现结构或接缝仍需返工时，暂停涂装并退回 Gate 3 复检。
  • 建立明度与分区图：把重点局部压成深、中、浅三阶，标出主色、辅助色、强调色及不可覆盖的纹理、接口和装配基准。
  • 比较三种层序：在同底材样片或同规格局部样上比较“先浅后深”“先深后提亮”“综合色底加重点色”三种方案，记录遮盖力、层数和干燥状态。
  • 执行可逆的小面积验证：先做底色和主要边界，再以薄层逐步推进；每增加一层都在正面、侧面和近距离检查细节是否被填平。
  • 检查遮盖与交界：在曲面转折、凹槽、透明嵌件和软硬材质交界处移除遮盖，确认无渗色、翘边、厚边或接口堵塞。
  • 完成双光源读回与记录：在自然侧光和工作灯下比较明度、饱和度、反光与边缘，将配方、层序、工具、问题和修正结果写入交接记录。

常见错误

以下错误会让重点局部失去验证作用，并把本可局部修正的问题带入整件涂装。

  • 把重点局部一次厚涂到目标颜色；后果是纹理、锐边和细小凹槽被填平，后续无法判断问题来自模型还是涂层。
  • 只比较颜色名称，不固定底漆、层序和光泽；后果是同一配方在不同表面出现色差，局部结论无法复现到整件。
  • 遮盖线直接跨过接缝或装配基准；后果是涂层形成厚边或堵塞接口，拆装后还可能撕裂相邻漆膜。
  • 只在强正光下确认效果；后果是侧光下的刷痕、渗色、边缘堆积与明度合并被遗漏，拍摄和展示时才暴露。
  • 局部验证失败后继续扩大涂装面积；后果是返工范围增加，并可能用颜色掩盖尚未通过 Gate 3 的结构或表面缺陷。

与五天课程的关系

当天主题对应 Day 3“灰模与色彩测试”的末段以及 Gate 3 实体验证。灰模已经完成结构、装配与表面检查后，重点局部验证用同底材、三阶明度、层序、遮盖和双光源读回，证明配色色板能够落到真实曲面，而不是只在纸面或屏幕上成立。

完成本阶段后，下一阶段进入 Day 4 的基础涂装或重点局部涂装，并继续处理整体分色、保护层、包装方向和产品说明。若局部的明度、边界、附着或细节保留不通过，则回到样片、底漆或遮盖方法调整，不把未经验证的方案扩展到整件。
