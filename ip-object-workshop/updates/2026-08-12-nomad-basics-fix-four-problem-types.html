具体问题

进入 Nomad 后，最容易出现的偏差是把学习目标写成一串菜单和笔刷名称：会移动、平滑、重构、切割，就以为模型已经完成修正。实际进入实体制作时，问题不会按软件菜单出现，而会表现为整体比例失衡、网格破面或重叠、薄壁与悬空、拆件接口和装配关系不成立。若只记操作，不先判断问题类别，同一个动作可能在错误位置反复使用。

这种偏差会直接影响 Day 2 的 Gate 2。过度平滑可能抹掉角色识别点，局部加厚可能改变装配间隙，随意合并可能让原本可拆的部件无法安排打印方向。Nomad 在五天流程中的价值不是展示掌握了多少功能，而是把可定位的问题修到可复检状态，并留下能进入拆件、双文件输出和切片预检的受控版本。

核心判断

修模前先把问题分为四类。第一类是比例与轮廓：从正面、侧面、背面和四分之三视角检查大体块、姿态、重心与主要负形。第二类是表面与网格：定位破面、孔洞、重叠、粘连和异常起伏。第三类是制造薄弱点：按目标尺寸检查薄壁、尖细件、悬空和易断连接。第四类是拆件与装配：确认分件边界、接口方向、定位结构、接触面和装配顺序。

动作是否正确，要看修正前后能否用同一证据复核，而不是看表面是否更光滑。每次只处理一个已标记问题，保存版本，再回到多视角、尺寸和装配条件复检；若修正会牵动核心身份或超出五天范围，就退回候选选择，或启用备选、局部样和降级出口。

步骤或标准

可按以下六项完成一次受控修模。每项都应产生可检查的视图、尺寸、部件关系或版本记录。

  • 建立修前快照：锁定模型版本、目标实体尺寸和正侧背视图，标出比例、轮廓、破面、薄壁、悬空及接口问题；未标记的问题不先动。
  • 先修大体块：在低细节状态调整头身比例、躯干体量、四肢或附属物姿态和主要负形；缩小预览与侧面视图都能读清后再进入局部。
  • 清理表面与网格：逐处处理孔洞、重叠、粘连、破面和异常凸凹，每完成一处就旋转检查相邻面，避免平滑动作把识别边缘一起消掉。
  • 复核最小厚度与连接：按真实输出尺寸测量薄片、尖端、承重点和悬空件；不满足材料与打印条件时，选择加厚、缩短、加支撑关系或改为独立分件。
  • 建立拆件和接口：明确主体、底座与配件边界，检查定位榫、接触面、装配方向和间隙；接口必须能从至少两个视角确认，不用外观遮挡代替结构。
  • 保存修后版本并复检：对照修前标记逐项勾销，保留未解决项和降级决定；只有身份、网格、厚度、重心、拆件与装配均有证据，才进入 GLB / STL 输出和 Gate 2 检查。

常见错误

以下错误都会让“会操作”与“模型可继续制造”之间出现断层。

  • 一开始就提高细分并雕刻小纹理；后果是大比例和重心仍未稳定，后续调整会破坏已投入的细节并增加修正成本。
  • 对所有表面连续使用平滑；后果是原作的硬边、转折和识别轮廓被抹掉，模型看似干净却失去对象身份。
  • 只在放大视图里修薄片和尖端；后果是缩放到真实尺寸后仍可能过薄、易断或无法布置支撑，问题被推迟到切片和打印。
  • 先合并全部部件再考虑拆件；后果是接口、打印方向和后处理空间难以安排，局部失败时也无法只重打受影响部件。
  • 覆盖原文件且不保存修前证据；后果是无法比较动作是否有效，也无法退回主、备或降级版本，Gate 2 缺少可复核记录。

与五天课程的关系

当天主题对应 Day 2“AI 三维初模与 Nomad 人工修模”及 Gate 2。Day 1 / Gate 1 已锁定对象、用途、尺寸、视觉输入和主 / 备 / 降级范围；Day 2 不要求系统学习 Nomad 的全部菜单，而是围绕比例轮廓、表面网格、薄壁悬空、拆件装配四类问题完成必要修正。

修正后的受控主模型还要经过 Gate 2 的身份、网格、真实厚度、重心、连接、拆件、装配和切片预检。通过后进入下一阶段 Day 3 的切片、首轮打印、灰模处理与 Gate 3 实体验证；未通过则继续留在 Day 2 修正，或按记录切换备选和降级出口。

事实 / 案例 / 完成度边界

本文依据课程主基线中的 Day 2、Gate 2 和 Day 3 交接要求整理。当天规划的原创“栖岬背负兽”四张图片用于示意修前标记、三种姿态比例比较、接口厚度实测与修后交接，均为课程方向示意图；它们不是学员作品、真实课堂、真实委托、已经发生的制作过程或完成成果。真实案例只有在来源、授权、输入版本、模型记录、切片和实物状态均可核验时才会明确标注，示意图不能替代真实案例。

五天内可推进的是与项目范围匹配的第一版受控模型、必要人工修正、拆件方案、GLB / STL，以及灰模、局部样或小尺寸实体样中的可行出口，不等于完成所有细节。完成度受输入成熟度、结构复杂度、尺寸、材料、设备、打印排程和修正次数影响；课程不承诺学完全部 Nomad 功能、一次修模即通过、一次打印成功、商业级精修、固定实体件数、正式包装印刷、批量生产、正式展览、授权成交或销售结果。
