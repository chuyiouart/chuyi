核心判断

一组资料能不能进入作品页，先看它是否回答清楚“这是哪一件作品、哪一版、完成到哪里”。图片要能对应实物或当前方向样，三维展示文件要与说明中的外形和配件一致，尺寸、材料、作者与来源则要有可核对的记录。文件能打开，只证明格式可读，不证明内容正确。

整理时以一张版本清单为中心，每个公开文件都写清用途、来源、更新时间和检查结果。再从访客会看到的顺序走一遍：首图、细节、模型、说明和行动入口。桌面与手机都能正常读取，链接没有指错，未完成项没有被写成成果，才进入正式部署或持续发布。

步骤或标准

上线前按同一版本逐项核对文件、说明和访客实际看到的结果。

  • 确定当天要整理的作品版本，列出标题、简短说明、尺寸、材料、作者与来源、完成状态、首图、细节图、三维展示文件和行动链接；确认不了的项目写成待补。
  • 建立一张版本清单，给每个文件记录用途、真实位置、来源、更新时间和当前状态。图片、模型与说明使用同一个版本标识，不靠“最终版”“最新”这类模糊文件名判断。
  • 逐张检查图片：首图是否对应当前作品，细节图能否回到整体中的具体部位，颜色和比例有没有明显误导，是否混入旧配件、无授权素材或把方向示意当成实物成果。
  • 单独检查展示模型。确认文件能加载、单位与朝向合理、主要部件和当前说明一致；GLB 可用于网页展示，但打印文件仍需另外检查封闭性、壁厚、连接和实际尺寸。
  • 把说明中的尺寸、材料、配件、作者、来源和完成状态逐项对回图片、模型或原始记录。找不到依据的内容不补写成事实，旧版本资料移出公开清单但保留内部来源记录。
  • 在桌面与约 390 像素手机宽度走完首图、图集、模型、说明和报名入口，逐个打开资源与链接；再只替换一个文件做最小更新测试，确认无关内容不变后保存本次清单。

常见错误

资料数量多不代表准备充分；下面这些做法会让页面内容失去版本依据。

  • 把文件名里带“最终版”的内容直接当成最新资料。后果是旧照片、旧模型或旧说明可能混进页面，同一作品出现多个互相冲突的版本。
  • 只确认图片和模型能打开，不核对它们是不是同一件作品。后果是页面看起来完整，尺寸、配件和外形却可能对不上，访客得到错误信息。
  • 为了补齐页面，让 AI 猜材料、尺寸、作者或完成状态。后果是没有来源的推测会被当成公开事实，也无法在实物或记录中复查。
  • 把 GLB 能显示当成打印文件已经合格。后果是单位、壁厚、封闭性、连接和支撑问题被漏掉，网页展示状态会被误当成可制造证明。
  • 一次同时换首图、模型、说明和链接。后果是出错后找不到是哪一项造成，也无法证明以后可以安全地只更新一个部分。

与短期课程的关系

这个主题对应第五阶段，也就是独立站、三维展示与持续发布。做完后要有一张同版资料清单、用途清楚的图片与展示模型、和记录一致的尺寸材料说明，以及一次桌面和手机检查。资源、链接与完成状态都能复查，未确认内容已经单独列出，才通过发布前检查。

3 天路线可以围绕一个已有作品完成资料盘点、同版整理和一个页面草稿所需的最小内容；4–5 天可继续接入图集、可选三维展示、移动端检查和最小更新测试。正式部署、域名、复杂交互、打印文件工程检查与长期运营仍按实际条件另行安排。

事实 / 案例 / 完成度边界

本文依据第五阶段的作品资料整理与发布验收方法整理。本页规划用原创陶瓷釉面人形“庭院归档员”，表现角色在安静庭院里整理同版图像石片、模型方向样与说明载体，并比较资料是否一致。当天四张图都是课程方向示意图，不是真实网站案例，也不是学员作品、真实课堂、已完成陶瓷烧制项目、真实委托或商业成果。真实案例必须另有清楚来源、使用许可、页面文件和公开验证记录。

3–5 天能做到哪一步，取决于已有图片、模型格式、资料完整度、页面基础、账号权限和修改次数。通常可围绕一个作品完成资料清单、同版核对、页面骨架所需内容和首轮桌面与手机检查；陶瓷烧制、打印文件工程验证、正式部署、复杂交互、专业无障碍审计和长期维护要另行评估。课程不承诺一次整理解决全部历史版本问题，也不承诺流量、订单、展览或销售结果。
