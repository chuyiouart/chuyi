# 初艺颜料详情知识调用协议

版本：1.0

日期：2026-07-16

适用：课程讲义、课程网页、PDF、教师手册、家长说明、五天培训、B2B 机构方案与内容执行命令

## 1. 目标

本协议把同一套颜料知识安全地调用到不同项目。输出首先帮助学习者识别“这是什么颜料”，再解释“它在当前媒介里怎么表现、如何实测、有什么边界”，不把数据库写成商品推荐或危险材料配方。

## 2. 数据入口与优先级

1. `knowledge-core/data/pigment-enrichment.json`：首选。`deep-reviewed-v1` 条目可调用身份判断、混色、操作、限制、替代和尽调来源。
2. `data/pigments.json`：全量索引。可调用 CI、名称、组成原文、透明度、耐光性、吸油量原始记录和风险筛查。
3. `knowledge-core/data/pigment-image-manifest.json`：图片与授权。只有本文件中存在且许可满足目标用途的图片才可进入发布物。
4. 具体品牌最新版 SDS / 技术资料：决定当次实际产品的危险分类、配方、使用和废弃要求。
5. Art is Creation 原页：只作为条目发现和历史线索，不作为现代安全结论的唯一证据，也不复制其长篇说明或配方。

冲突时采用更具体、更新、风险更严格的资料，并在输出中保留差异，不强行合并成一个确定答案。

## 3. 审校等级

### `deep-reviewed-v1`

可以进入课程初稿和内部 PDF 样稿，但发布前仍需检查目标品牌 SDS、媒介和受众。必须同时显示 CI 编码与资料来源。

### `structured-unverified`

只可用于检索、目录、待办和通用试片操作卡。不得写成“已证实”“推荐给学生”或出版定稿；化学组成中文辅助初译必须人工复核。

### 风险 C / D 或含铅、镉、汞、砷、铬酸盐等触发项

学生版、家庭版和普通机构培训默认不做实际操作。只输出：材料身份、历史用途、风险原因、无该危险成分的替代思路和专业管理边界。禁止生成制备、干粉研磨、喷涂、加热或打磨步骤。

## 4. 每次调用必须输出的最小结构

```text
颜料身份：中文名 / English / CI
为什么与本节课相关：1 句话
观察重点：色相、明度、彩度、透明/遮盖、着色力中的 2–3 项
安全操作：本课能做什么、不能做什么
验证动作：至少 1 个可留档试片
审校状态：deep-reviewed-v1 或 structured-unverified
来源：现代权威来源 + 具体产品 SDS（如涉及实际材料）
```

不能确定时写“待核验”，不得由商品名、屏幕色块或同一 CI 的其他品牌表现推断。

## 5. 标准五步操作卡

1. 记录管身/包装的 CI、胶结料、品牌、批次和 SDS 日期。
2. 在同一底材做原色厚涂、逐级混白、刮薄、透明罩染四格试色。
3. 跨黑白分界线平涂，干后判断实际遮盖力。
4. 在 1、3、7 天以相同光源拍照，记录表面、干燥、色相和光泽变化。
5. 保留一半避光、另一半可控曝光，形成长期耐光观察档案。

所有结果只代表“这支产品 + 当前胶结料 + 当前底材 + 当前操作”。不得直接推广到同一 CI 的所有产品。

## 6. 不同项目的调用模板

### 课程单节

选择 1 个主颜料与 1 个对照颜料。知识卡不超过课程正文的 15%，必须服务本节视觉判断；例如白色课比较 PW6/PW4，蓝色冷暖课比较 PB29/PB15:3。

### PDF 与教师手册

学生版只保留身份、观察重点和安全操作；教师版增加来源、误区、替代和讨论问题。图片下方必须显示作者、许可和来源页。

### 五天培训

第 1 天建立 CI 和试片方法；第 2–4 天把颜料身份嵌入模型/绘画任务；第 5 天整理个人材料档案。危险颜料只做案例和替代判断。

### B2B 机构方案

输出“机构材料白名单 + 替代清单 + SDS 台账 + 教师操作卡”。不得把全量 872 条直接变成采购清单；应按年龄、场地通风、废物管理和师资能力筛选。

### 网站详情页

`data/pigment-enrichment-data.js` 由 JSON 构建，支持 `file://` 离线使用。更新 JSON 或图片清单后运行：

```powershell
python knowledge-core\scripts\build_pigment_enrichment.py
```

不要手工同时编辑 JSON 与生成后的 JS，以免两份数据漂移。

## 7. 图片调用规则

- 只从 `pigment-image-manifest.json` 取图；保留 `creator`、`license`、`source_page` 和修改说明。
- Public domain / CC0 仍保留来源；CC BY-SA 必须保留作者和许可，并确认目标发布方式满足同许可要求。
- 粉末、矿物或历史样本图统一标注“材料外观示意”，不能替代品牌涂膜试色或色度标准。
- PDF 印刷、网页屏幕和实物颜料之间不得用“颜色完全一致”表述。

## 8. 执行命令可直接采用的提示词

```text
读取 knowledge-core/PIGMENT-DETAIL-CALLING-PROTOCOL.md，按其中的数据优先级、审校等级、安全边界和图片许可执行。
再读取 knowledge-core/data/pigment-enrichment.json 与 data/pigments.json。
只调用与当前课程目标直接相关的颜料；逐条显示 CI 和审校状态。
deep-reviewed-v1 可摘要进入初稿；structured-unverified 只能作为待核验索引与通用试片卡。
涉及危险颜料时只给识别、风险、替代和专业管理边界，不生成制备、干粉、喷涂、加热或打磨步骤。
使用图片前核对 knowledge-core/data/pigment-image-manifest.json 并完整保留署名、许可和来源。
```
